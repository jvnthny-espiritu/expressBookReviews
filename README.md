# Express Book Reviews API

A professional RESTful API application for managing books and user reviews with JWT-based authentication. This project demonstrates industry best practices in Node.js/Express development.

## 🌟 Features

- 📚 Browse books by ISBN, author, or title
- 👤 User registration and authentication using JWT
- ✍️ Add, update, and delete book reviews (authenticated users)
- 🔒 Secure routes with JWT token verification
- 📝 Clean MVC architecture
- ✅ Comprehensive error handling and input validation
- 🧪 Full test coverage with Jest
- 📖 Well-documented API endpoints

## 🚀 Quick Start

```bash
cd final_project
npm install
npm start
```

The server will start on `http://localhost:5000`
